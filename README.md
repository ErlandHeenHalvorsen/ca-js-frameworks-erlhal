## Report

This project was made with React + Vite + Tailwind. The task of building a web-shop with React war a learningful experience, and i have aquired knowledge i'm sure i will get a use for later.

The main difficulty was keeping track of my css, ironically. I started using .module.css way of styling, and quickly found out that i hated it. I started using normal css files, and that worked well. In the end when i ran out of time i started writing Tailwindclasses directly into the jsx, wich i personally find messy, but it is efficient.

Other than Styling and design i think the project went well, and i'm looking forward to my next React Project!
